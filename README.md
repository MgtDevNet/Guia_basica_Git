# Guía Definitiva de Git y GitHub desde la Terminal

Bienvenido/a a la referencia rápida y práctica para dominar el control de versiones paso a paso y sin rodeos.

---

## ¿De qué trata este repositorio?

Este repositorio reúne una **guía estructurada y accesible en formato Markdown** sobre el uso de **Git y GitHub** utilizando exclusivamente la terminal Bash.

Está diseñado para ser una **consulta rápida y directa**, ideal tanto para quienes están dando sus primeros pasos en el control de versiones como para quienes buscan repasar comandos clave en su día a día.

---

## Estructura del Contenido

El aprendizaje está dividido estratégicamente en **dos archivos principales**:

### 1. `parte_1_git.md` — Domina Git Local
> *Aprende a gestionar la historia y los cambios de tus proyectos en tu máquina local.*

- **Definiciones claras:** Entiende qué es un repositorio, el *staging area*, *commits*, ramas (*branches*) y fusiones (*merges*).
- **Comandos esenciales:** Desde `git init` y `git status` hasta `git log`, `git checkout` y `git rebase`.
- **Ejemplos prácticos:** Casos de uso reales paso a paso para perderle el miedo a la terminal.

---

### 2. `parte_2_github.md` — Colaboración en la Nube
> *Lleva tu código a la nube, trabaja en equipo y contribuye a proyectos open source.*

- **Conceptos clave:** Repositorios remotos, *Pull Requests* (PR), *Forks*, *Issues* y la configuración de llaves SSH/Tokens.
- **Comandos de sincronización:** Aprende a dominar `git remote`, `git push`, `git fetch` y `git pull`.
- **Flujos de trabajo colaborativos:** Buenas prácticas para crear PRs, resolver conflictos remotos y gestionar proyectos.

---

## ¿Para quién es esta guía?

- **Principiantes:** Que quieren aprender Git desde cero de forma estructurada.
- **Desarrolladores/as:** Que buscan una hoja de ruta (*cheat sheet*) rápida a la mano.
- **Estudiantes:** Que necesitan entender cómo trabajar en equipo para sus proyectos académicos o de código abierto.

---

## ¿Cómo usar este repositorio?

1. **Lee a tu propio ritmo:** Empieza por `parte_1_git.md` para dominar los fundamentos locales.
2. **Pasa a la nube:** Continúa con `parte_2_github.md` cuando estés listo/a para conectar tus repositorios con GitHub.
3. **Práctica interactiva:** Abre tu terminal Bash, crea un directorio de prueba y pon a prueba cada comando conforme vas leyendo.
